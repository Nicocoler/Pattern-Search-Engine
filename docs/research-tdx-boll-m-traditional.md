# 通达信「BOLL-M 布林线-传统版」计算方式调研

调研日期：2026-07-28  
范围：主图指标「BOLL-M 布林线-传统版」的中轨/上下轨算法、默认参数、与系统「标准 BOLL」及经典 Bollinger Bands 的差异。

## 结论摘要

1. **中轨**：收盘价的 **N 日简单移动平均**（`MA(CLOSE,N)`；等价于 `SMA(CLOSE,N,1)`）。
2. **波动度量**：不用一行 `STD(...)`，而是用手写方差开方：`(C−MID)²` → N 日均 → `SQRT`（总体标准差语义，÷N）。
3. **上下轨**：`中轨 ± 2 × 该标准差`（倍数固定为 2，多数复刻公式不暴露 P 参数）。
4. **画图习惯**：上下轨（及部分版本的中轨）常再套一层 `REF(...,1)`，即 **相对当日 K 线滞后 1 根** 显示。
5. **默认周期**：`N = 20`。
6. **置信度**：系统内置公式多为加密，网上为社区复刻；与官方肉眼核对时常有「仍有细微差别」的说明。本仓库 `apply_boll` 按该复刻逻辑对齐。

## 复刻公式（社区共识版）

参数：`N` 默认 20；倍数固定 2。

```text
MID := MA(C, N);                 // 或 SMA(C, N, 1)，M=1 时等价于简单均线
VART1 := POW((C - MID), 2);
VART2 := MA(VART1, N);           // 总体方差 ≈ mean((C-MID)^2)
VART3 := SQRT(VART2);            // 总体标准差（≈ STDP，非 STD）
UPPER := MID + 2 * VART3;
LOWER := MID - 2 * VART3;

// 画图输出（传统版常见写法）
BOLL : REF(MID, 1);
UB   : REF(UPPER, 1);
LB   : REF(LOWER, 1);
```

等价数学形式（对第 t 根 K 线，先算未滞后值）：

\[
\begin{aligned}
\text{MID}_t &= \frac{1}{N}\sum_{i=0}^{N-1} C_{t-i} \\
\sigma_t &= \sqrt{\frac{1}{N}\sum_{i=0}^{N-1}(C_{t-i}-\text{MID}_t)^2} \\
\text{UPPER}_t &= \text{MID}_t + 2\sigma_t \\
\text{LOWER}_t &= \text{MID}_t - 2\sigma_t
\end{aligned}
\]

若采用 `REF(...,1)`，界面上第 t 日画出的三轨取自 \(t-1\) 日的计算结果。

## 与通达信「标准 BOLL」的差异

| 项目 | 标准 BOLL（常见写法） | BOLL-M 传统版（复刻） |
|------|----------------------|----------------------|
| 中轨 | `MA(CLOSE,N)` | 同左 |
| 标准差 | 公式写 `STD(CLOSE,N)`（帮助称「估算标准差」） | `√MA((C−MID)²,N)` 手写方差开方 |
| 倍数 | 参数 `M`，默认 2 | 写死 `2` |
| 滞后 | 通常当日值直接画 | 常 `REF(...,1)` |

官方函数表（通达信公式帮助）：

- `STD(X,N)`：估算标准差  
- `STDP(X,N)`：总体标准差  

来源：<https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html>

**注意（未完全证实）：**

1. 帮助字面暗示 `STD` 用分母 N−1、`STDP` 用 N；但社区实测常称通达信里二者数值接近或同为 ÷N，**不能仅凭帮助断定带宽差约 2.6%**，需同股同日对表。
2. 复刻式 `MA(POW((C-MID),2),N)` 中，每一日的偏差用的是**当日滚动 MID**，再对偏差平方做均；这与「同一窗口内相对同一个均值再 `STDP`」在边界上可能略有差别，多数日线场景下差异很小。

## 与经典 John Bollinger 布林带

John Bollinger / 常见百科表述采用 **population method（分母 N）** 的标准差，再乘倍数。  
因此「传统版」手写总体标准差 **更接近经典 Bollinger 的标准差约定**；通达信「标准 BOLL」是否因使用 `STD` 而变成样本标准差，取决于软件对 `STD` 的真实实现，不宜先验断言。

传统版相对经典的主要可见差异往往是：**上下轨（及部分版本中轨）再 `REF(...,1)` 滞后一根 K 线**。

## 与本仓库实现对齐

**目标权威：通达信「BOLL-M 布林线-传统版」。**

`backend/app/indicator_engine/engine.py` 中 `apply_boll` 即为全项目唯一布林出口，按传统版复刻：

- `rolling.mean` → 中轨  
- `(close-mid)^2` 再 `rolling.mean` 再 `sqrt` → 总体标准差（÷N）  
- 三轨统一 `shift(1)` → `REF(...,1)`  
- 默认 `N=20`、`k=2`；前 `n` 行置 NaN  

**不是**通达信「标准 BOLL」（`MA ± M*STD`、通常不滞后）。

## 未证实 / 待本地核验

1. 当前安装的通达信金融终端里，系统加密的「BOLL-M」是否 100% 等于上述复刻（需同股同日对比三轨数值）。  
2. 中轨是否也滞后 1 日：有的复刻中轨当日画、上下轨滞后；有的三轨皆滞后。本仓库三轨统一 `shift(1)`。  
3. 停牌/复权处理是否与通达信完全一致（本仓库另有停牌平滑逻辑）。
